# Tools

Open source tools built by and for Sulitânia.

## What is here

- **website/** — Cursor instructions for syntrociety.com (Next.js, 7 languages)
- **translation-check/** — GitHub Action for multilingual quality assurance
- **document-generation/** — PDF and document generation scripts
- **newsletter/** — Translation and send scripts

## Overview

All tools published under CC BY-SA 4.0. Each folder contains a README: what it does, how to set it up, what to adapt.
