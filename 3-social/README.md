# Social

How we live and work together, and how we engage the wider community.

## Overview

**16 members from 7 nationalities.** Families with children, long-term residents, rotating volunteers.

**8+ workshops** delivered since 2023 on syntropic agroforestry, consent governance, regenerative systems.

Stakeholder map covers four quadruple helix sectors:
- Academia: University of Algarve
- Government: Município de Castro Marim
- Business: 19 micro-enterprises
- Civil society: Friends of Sulitânia, Baixo Guadiana Seed Guardians, Lago da Colina neighbourhood
