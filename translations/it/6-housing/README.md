# Alloggio

Alloggio ecologico rilocabile: progettazione, costruzione e politica.

## Cosa c'è qui

- **tiny-house-unit-1/** — Specifiche progettuali, registro di costruzione, lezioni apprese
- **policy/** — Documento di posizione per il comune, panorama normativo

## Panoramica

Sulitânia sta sviluppando un modello di **alloggio ecologico rilocabile** adatto al Portogallo rurale. La Tiny House Unità 1 è in costruzione ad aprile 2026.

Questo risponde a una lacuna nella politica abitativa rurale portoghese: non esiste un quadro giuridico per abitazioni non permanenti ed ecologiche. Il nostro documento di posizione — presentato al Município de Castro Marim — sostiene una via normativa.
