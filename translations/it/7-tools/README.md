# Strumenti

Strumenti open source creati da e per Sulitânia.

## Cosa c'è qui

- **website/** — Istruzioni Cursor per syntrociety.com (Next.js, 7 lingue)
- **translation-check/** — GitHub Action per la garanzia di qualità multilingue
- **document-generation/** — Script per la generazione di PDF e documenti
- **newsletter/** — Script di traduzione e invio

## Panoramica

Tutti gli strumenti sono pubblicati sotto CC BY-SA 4.0. Ogni cartella contiene un README che spiega cosa fa, come configurarlo e cosa adattare per uso proprio.
