# Leren

Wat we meten, waarover we reflecteren en wat we hebben geleerd — inclusief fouten.

## Wat hier staat

- **indicators.md** — Wat we meten, hoe vaak, door wie en in welk format
- **quarterly-reflections/** — Eerlijke kwartaaloverzichten van wat er is gebeurd
- **mistakes-and-lessons.md** — Wat er mis ging en wat we hebben geleerd

## Overzicht

Werkcyclus: **observeren → prototypen → evalueren → aanpassen**.

Het **fouten-en-lessen-document** is bewust ongebruikelijk. De meeste organisaties publiceren niet wat er mis ging. Wij wel. De woonsituatie, vroege bestuursspanning, financiële druk — dit is wat een andere startende gemeenschap het meest nodig heeft om te weten.

Kwartaalreflecties beginnen met K2 2026.
