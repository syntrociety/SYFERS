## Overzicht

Het economisch model van Sulitânia is gebaseerd op drie pijlers:

**10%-circulatiemodel** — Elke micro-onderneming draagt 10% van de omzet bij aan het gedeelde fonds van de coöperatie.

**Friends of Sulitânia** — Ondersteuningsprogramma waarmee mensen buiten de coöperatie maandelijks kunnen bijdragen.

**19 micro-ondernemingen** verdeeld over 8 coöperatieve secties. Totale gedocumenteerde ledeninvestering per april 2026: bijna EUR 100.000.
