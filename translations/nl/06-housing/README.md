# Wonen

Ecologische verplaatsbare woningbouw: ontwerp, constructie en beleid.

## Wat hier staat

- **tiny-house-unit-1/** — Ontwerpspecificaties, bouwlogboek, geleerde lessen
- **policy/** — Positiepaper voor de gemeente, regelgevingslandschap

## Overzicht

Sulitânia ontwikkelt een model voor **ecologische verplaatsbare woningbouw** geschikt voor ruraal Portugal. Tiny House Unit 1 is per april 2026 in aanbouw.

Dit adresseert een lacune in het Portugese plattelandsbeleid: er bestaat geen wettelijk kader voor niet-permanente, ecologische woningen. Ons positiepaper — gepresenteerd aan het Município de Castro Marim — pleit voor een regulatoir pad.
