# Energie

Gemeenschapsenergie bij Sulitânia: ontwerp, data en replicatie.

## Wat hier staat

- **system-specs.md** — Volledige systeembeschrijving: componenten, vermogen, kosten
- **production-data/** — Maandelijkse productielogboeken (vanaf mei 2026)
- **replication-guide.md** — Hoe een andere gemeenschap een vergelijkbaar systeem kan bouwen

## Overzicht

Autonoom zonne-energiesysteem, onafhankelijk van het hoofdnet van de quinta:

- **22,3 kWp** fotovoltaïsch vermogen
- **48 kWh** batterijopslag
- Interne meting voor gemeenschappelijke energiedeling
- Installatie voltooid in 2024
- Totale investering: **EUR 18.300**
