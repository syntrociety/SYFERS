# Ecologie

Wat we verbouwen, hoe we het verbouwen en wat we leren.

## Wat hier staat

- **food-forest/** — Plantplan, soortenlijst, oprichtingsgids, monitoring
- **ssaaflab/** — Experimenteel syntroop perceel: protocollen, experimentenlogboek
- **seed-bank/** — Soortenlijst zaadbank, handleiding zaadsparen
- **water/** — Ontwerp en beheer van het irrigatiesysteem

## Overzicht

Sulitânia beheert een **syntroopf agroforestry-voedselwoud van 1.481 m²** op Quinta da Fornalha, Castro Marim. Per april 2026: **1.688 planten van 61+ soorten** verdeeld over meerdere luifellagen.

Het **SSAAFLab** (130 m²) is een experimenteel subperceel voor gecontroleerd syntroop onderzoek. Bodembiologie beoordeeld in september 2025 (Jake Corin) — resultaten in `food-forest/monitoring/`.

De **zaadbank** werd gestart in 2024 en richt zich op open-bestuivende, lokaal aangepaste variëteiten voor het oostelijke Algarve.
