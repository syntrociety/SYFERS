# Hulpmiddelen

Open source hulpmiddelen gebouwd door en voor Sulitânia.

## Wat hier staat

- **website/** — Cursor-instructies voor syntrociety.com (Next.js, 7 talen)
- **translation-check/** — GitHub Action voor meertalige kwaliteitsborging
- **document-generation/** — Scripts voor PDF- en documentgeneratie
- **newsletter/** — Scripts voor vertaling en verzending

## Overzicht

Alle hulpmiddelen worden gepubliceerd onder CC BY-SA 4.0. Elke map bevat een README met uitleg over het doel, de installatie en wat je moet aanpassen voor eigen gebruik.
