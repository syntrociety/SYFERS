# Bestuur

Hoe Sulitânia beslissingen neemt, conflicten oplost en zichzelf verantwoordt.

## Wat hier staat

- **principles.md** — De 8 bestuursprincipes
- **statutes/** — Statuten van de coöperatie (PT + EN)
- **assembly-minutes/** — Geanonimiseerde notulen van elke Algemene Vergadering
- **decision-log.md** — Alle besluiten sinds mei 2023: datum, methode, uitkomst
- **conflict-resolution.md** — Hoe conflict als informatie wordt behandeld
- **templates/** — Sjablonen voor agenda, notulen en besluitrecords

## Overzicht

Sulitânia gebruikt consent-gebaseerd bestuur. Een besluit wordt genomen wanneer niemand een gemotiveerd, zwaarwegend bezwaar heeft — niet wanneer iedereen het eens is.

Sinds mei 2023: **3 Algemene Vergaderingen** en **32 gedocumenteerde werkvergaderingen**.

Het besluitenlogboek is het meest bruikbare document in deze map voor iedereen die wil begrijpen hoe we in de praktijk besturen.
