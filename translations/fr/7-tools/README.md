# Outils

Outils open source créés par et pour Sulitânia.

## Ce qui est ici

- **website/** — Instructions Cursor pour syntrociety.com (Next.js, 7 langues)
- **translation-check/** — GitHub Action pour l'assurance qualité multilingue
- **document-generation/** — Scripts de génération de PDF et de documents
- **newsletter/** — Scripts de traduction et d'envoi

## Vue d'ensemble

Tous les outils sont publiés sous CC BY-SA 4.0. Chaque dossier contient un README expliquant ce qu'il fait, comment le configurer et ce qu'il faut adapter pour son propre usage.
