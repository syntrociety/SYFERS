# Apprentissage

Ce que nous mesurons, sur quoi nous réfléchissons et ce que nous avons appris — y compris les erreurs.

## Ce qui est ici

- **indicators.md** — Ce que nous mesurons, à quelle fréquence, par qui et dans quel format
- **quarterly-reflections/** — Comptes rendus trimestriels honnêtes de ce qui s'est passé
- **mistakes-and-lessons.md** — Ce qui a mal tourné et ce que nous avons appris

## Vue d'ensemble

Rythme de travail : **observer → prototyper → évaluer → ajuster**.

Le **document erreurs et leçons** est délibérément inhabituel. La plupart des organisations ne publient pas ce qui a mal tourné. Nous le faisons. La situation du logement, les tensions initiales de gouvernance, les pressions financières — c'est ce qu'une autre communauté qui démarre a le plus besoin de savoir.

Les réflexions trimestrielles commencent au T2 2026.
