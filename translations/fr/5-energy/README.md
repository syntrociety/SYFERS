# Énergie

Énergie communautaire à Sulitânia : conception, données et réplication.

## Ce qui est ici

- **system-specs.md** — Description complète du système : composants, capacité, coûts
- **production-data/** — Journaux de production mensuels (à partir de mai 2026)
- **replication-guide.md** — Comment une autre communauté peut construire un système comparable

## Vue d'ensemble

Système d'énergie solaire autonome, indépendant du réseau principal de la quinta :

- **22,3 kWp** de capacité photovoltaïque
- **48 kWh** de stockage en batterie
- Comptage interne pour le partage d'énergie communautaire
- Installation achevée en 2024
- Investissement total : **EUR 18 300**
