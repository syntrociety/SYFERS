# Gouvernance

Comment Sulitânia prend des décisions, résout les conflits et rend compte.

## Ce qui est ici

- **principles.md** — Les 8 principes de gouvernance
- **statutes/** — Statuts de la coopérative (PT + EN)
- **assembly-minutes/** — Procès-verbaux anonymisés de chaque Assemblée Générale
- **decision-log.md** — Toutes les décisions depuis mai 2023 : date, méthode, résultat
- **conflict-resolution.md** — Comment le conflit est traité comme information
- **templates/** — Modèles d'ordre du jour, procès-verbaux et enregistrements de décision

## Vue d'ensemble

Sulitânia utilise une gouvernance par consentement. Une décision est prise lorsque personne n'a d'objection motivée et prioritaire — pas quand tout le monde est d'accord.

Depuis mai 2023 : **3 Assemblées Générales** et **32 réunions de travail documentées**.

Le journal des décisions est le document le plus utile dans ce dossier pour quiconque veut comprendre comment nous gouvernons en pratique.
