# Energie

Gemeinschaftsenergie bei Sulitânia: Planung, Daten und Replikation.

## Was hier ist

- **system-specs.md** — Vollständige Systembeschreibung: Komponenten, Kapazität, Kosten
- **production-data/** — Monatliche Produktionsprotokolle (ab Mai 2026)
- **replication-guide.md** — Wie eine andere Gemeinschaft ein vergleichbares System bauen kann

## Überblick

Autonomes Solarenergiesystem, unabhängig vom Hauptnetz der Quinta:

- **22,3 kWp** Photovoltaikkapazität
- **48 kWh** Batteriespeicher
- Interne Zählung für gemeinschaftliche Energieteilung
- Installation abgeschlossen 2024
- Gesamtinvestition: **EUR 18.300**
