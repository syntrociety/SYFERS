# Werkzeuge

Open-Source-Werkzeuge, entwickelt von und für Sulitânia.

## Was hier ist

- **website/** — Cursor-Anweisungen für syntrociety.com (Next.js, 7 Sprachen)
- **translation-check/** — GitHub Action zur mehrsprachigen Qualitätssicherung
- **document-generation/** — PDF- und Dokumentenerstellungsskripte
- **newsletter/** — Übersetzungs- und Versandskripte

## Überblick

Alle Werkzeuge werden unter CC BY-SA 4.0 veröffentlicht. Jeder Ordner enthält eine README mit Erklärung des Zwecks, der Einrichtung und was für den eigenen Gebrauch angepasst werden muss.
