# Wohnen

Ökologisches versetzbares Wohnen: Planung, Bau und Politik.

## Was hier ist

- **tiny-house-unit-1/** — Entwurfsspezifikationen, Bauprotokoll, gelernte Lektionen
- **policy/** — Positionspapier für die Gemeinde, regulatorisches Umfeld

## Überblick

Sulitânia entwickelt ein Modell für **ökologisches versetzbares Wohnen** geeignet für das ländliche Portugal. Tiny House Einheit 1 befindet sich im April 2026 im Bau.

Dies adressiert eine Lücke in der portugiesischen Landhausbauplanung: Es gibt keinen rechtlichen Rahmen für nicht permanente, ökologische Wohngebäude. Unser Positionspapier — der Gemeinde Castro Marim vorgelegt — plädiert für einen regulatorischen Weg.
