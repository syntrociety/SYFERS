# Ferramentas

Ferramentas de código aberto criadas pela e para a Sulitânia.

## O que está aqui

- **website/** — Instruções Cursor para syntrociety.com (Next.js, 7 línguas)
- **translation-check/** — GitHub Action para garantia de qualidade multilingue
- **document-generation/** — Scripts de geração de PDF e documentos
- **newsletter/** — Scripts de tradução e envio

## Visão geral

Todas as ferramentas são publicadas sob CC BY-SA 4.0. Cada pasta contém um README explicando o que faz, como configurar e o que adaptar para uso próprio.
