# Energia

Energia comunitária na Sulitânia: concepção, dados e replicação.

## O que está aqui

- **system-specs.md** — Descrição completa do sistema: componentes, capacidade, custos
- **production-data/** — Registos mensais de produção (a partir de maio de 2026)
- **replication-guide.md** — Como outra comunidade pode construir um sistema semelhante

## Visão geral

Sistema de energia solar autónomo, independente da rede principal da quinta:

- **22,3 kWp** de capacidade fotovoltaica
- **48 kWh** de armazenamento em baterias
- Medição interna para partilha de energia comunitária
- Instalação concluída em 2024
- Investimento total: **EUR 18.300**
