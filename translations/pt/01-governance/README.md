# Governança

Como a Sulitânia toma decisões, resolve conflitos e presta contas.

## O que está aqui

- **principles.md** — Os 8 princípios de governança
- **statutes/** — Estatutos da cooperativa (PT + EN)
- **assembly-minutes/** — Actas anonimizadas de cada Assembleia Geral
- **decision-log.md** — Todas as decisões desde maio de 2023: data, método, resultado
- **conflict-resolution.md** — Como o conflito é tratado como informação
- **templates/** — Modelos de ordem do dia, actas e registos de decisão

## Visão geral

A Sulitânia utiliza governança por consenso. Uma decisão é tomada quando ninguém tem uma objeção fundamentada e prioritária — não quando toda a gente concorda.

Desde maio de 2023: **3 Assembleias Gerais** e **32 reuniões de trabalho documentadas**.

O registo de decisões é o documento mais útil desta pasta para quem quiser compreender como governamos na prática.
