# Herramientas

Herramientas de código abierto creadas por y para Sulitânia.

## Qué hay aquí

- **website/** — Instrucciones Cursor para syntrociety.com (Next.js, 7 idiomas)
- **translation-check/** — GitHub Action para garantía de calidad multilingüe
- **document-generation/** — Scripts de generación de PDF y documentos
- **newsletter/** — Scripts de traducción y envío

## Visión general

Todas las herramientas se publican bajo CC BY-SA 4.0. Cada carpeta contiene un README explicando qué hace, cómo configurarlo y qué adaptar para uso propio.
