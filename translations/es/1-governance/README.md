# Gobernanza

Cómo Sulitânia toma decisiones, resuelve conflictos y rinde cuentas.

## Qué hay aquí

- **principles.md** — Los 8 principios de gobernanza
- **statutes/** — Estatutos de la cooperativa (PT + EN)
- **assembly-minutes/** — Actas anonimizadas de cada Asamblea General
- **decision-log.md** — Todas las decisiones desde mayo de 2023: fecha, método, resultado
- **conflict-resolution.md** — Cómo se trata el conflicto como información
- **templates/** — Plantillas de orden del día, actas y registros de decisión

## Visión general

Sulitânia utiliza gobernanza por consentimiento. Una decisión se toma cuando nadie tiene una objeción razonada y prioritaria — no cuando todos están de acuerdo.

Desde mayo de 2023: **3 Asambleas Generales** y **32 reuniones de trabajo documentadas**.

El registro de decisiones es el documento más útil de esta carpeta para quien quiera entender cómo gobernamos en la práctica.
