# SYFERS

Repository for documentation of **SYFERS**: *Syntropic Framework for Encoding a Regenerative Society*.

## Structure

Documents in this repository are organized by language:

```text
/[language]/...
```

Examples:

```text
/en/...
/nl/...
/fr/...
```

## Guidelines

- Use one root-level folder per language.
- Place all documents for that language inside its folder.
- Keep structure and content as consistent as possible across languages.
