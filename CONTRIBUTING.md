# Contributing to SYFERS

## Who can contribute

**Sulitânia members** — direct write access to all sections.

**External contributors** — welcome to propose via pull request. All external contributions are reviewed before merging.

We particularly welcome contributions from:
- Other regenerative communities documenting similar work
- Researchers working on ORRI, agroecology, or cooperative governance
- Practitioners who have tested and adapted our templates

## What to contribute

Good: corrections, translations, monitoring data, adapted templates with notes.

Please do not submit: personal data, individual financial records, content contradicting CC BY-SA.

## How to contribute

1. Fork this repository
2. Create a descriptive branch (e.g., `add-seed-bank-catalogue`)
3. Make focused, descriptive commits
4. Submit a pull request explaining what and why
5. A Sulitânia member will review within two weeks

## Style

Plain language. Consistent Markdown. Dates on all log entries.
